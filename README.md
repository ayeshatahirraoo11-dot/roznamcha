# Roznamcha: week 3 starter (step 1)

This is Roznamcha, the course app of Mobile Application Development. You build it one step a week from week 3 to week 15, in this repo. This week is step 1: the welcome screen.

This project needs Flutter 3.50.0 or newer.

## How to run

1. Connect your Android phone to your laptop with a USB cable. USB debugging must be on.
2. Open a terminal in this folder and run these two commands:

   ```bash
   flutter pub get
   flutter run
   ```

The first build takes several minutes. The untouched starter shows crossed boxes where your work goes.

## Your tasks

Read `lib/main.dart` and `lib/screens/welcome_screen.dart` first; the comments explain the given code. Then do TODO 1 in `lib/main.dart` and TODO 2 to 6 in `lib/screens/welcome_screen.dart` (TODO 2 also edits `pubspec.yaml`). The handout explains each, and shows the design.

## Tests

Run the tests with this command:

```bash
flutter test
```

On the untouched starter, 2 tests pass and 9 fail. The two that pass check the given code. The failing tests are expected. GitHub Actions runs the same tests on every push, so it shows a red cross until you finish. When all six TODOs are done, the last line says `All tests passed!`
